# ExitBoost — VPN по ключу и обход DPI для Windows

Приложение для Windows: подключается к VPN по обычному ключу (VLESS, VMess,
Trojan, Shadowsocks, Hysteria2), пускает через него только нужные
сайты и программы (или весь трафик — с подтверждением) и умеет обходить
блокировки DPI через движок zapret.

Есть графическое приложение (WPF) и консольный клиент.

---

## Установка

1. Откройте [Releases](https://gitlab.com/karpachv99/ExitBoost/-/releases) и скачайте `ExitBoost-<версия>-setup.exe`.
2. Запустите установщик и нажмите «Далее» — ExitBoost появится в меню «Пуск»
   (и на рабочем столе), как обычная программа.
3. Удаление — через «Параметры → Приложения» или ярлык «Удалить ExitBoost».

Установщик кладёт программу в `Program Files\ExitBoost` (нужны права
администратора — они всё равно нужны приложению) и умеет ставить «только для
меня» без прав администратора. Рядом с установщиком в релизе лежит
`ExitBoost-<версия>-win-x64.zip` — портативная версия без установки.

## Возможности

| Возможность | Как работает |
|---|---|
| VPN по ключу | Ядро sing-box, ключи вставляются строкой или загружаются подпиской по ссылке |
| Список локаций | Ключи сгруппированы по странам, группы сворачиваются; видно пинг, потери, джиттер и качество |
| Подключение в один клик | Двойной клик по локации подключает VPN по этому ключу и включает обход DPI |
| Раздельное подключение | По умолчанию — только выбранные сайты и программы; весь трафик — с явным подтверждением |
| Обход DPI | zapret + каталог стратегий Flowseal (14 пресетов), запуск кнопкой «Применить» |
| Готовый список заблокированных | Переключаемый пресет «стандартный список заблокированных сервисов РФ» (itdoginfo/allow-domains) или полный реестр РКН; применяется и к обходу DPI, и к VPN |
| Тест скорости | Замер пинга, скачивания и отдачи через текущее соединение (Cloudflare) |
| Полная очистка | При выходе гасятся VPN, все процессы zapret и драйвер WinDivert |
| Обновления | Манифест `update.json` на GitLab, проверка SHA-256, докачка и отдельный updater с резервной копией и откатом |
| Консольный клиент | Те же действия из командной строки |

## Готовый список заблокированных сервисов

В разделах «Обход DPI» и «VPN по ключу» есть один общий переключатель
«Готовый список заблокированных сервисов РФ». Список добавляется к вашим
доменам (сами домены в поле не меняются) и работает сразу в двух местах:
как hostlist для zapret и как домены для маршрутизации sing-box.

| Вариант | Что это | Размер |
|---|---|---|
| Не использовать | Только домены, введённые вручную | — |
| Стандартный список | Курируемый набор [itdoginfo/allow-domains](https://github.com/itdoginfo/allow-domains) (`Russia/inside-raw.lst`): заблокированные в РФ сервисы и категории — YouTube, Discord, Meta, Twitter, TikTok, новости, аниме и т. д. | ~1,2 тыс. доменов |
| Полный реестр РКН | [AbbeyLubber/ru-blocklist-aggregator](https://github.com/AbbeyLubber/ru-blocklist-aggregator) (`blocked/rkn-domain.txt`) — весь реестр, обновляется еженедельно | ~1,67 млн доменов |

Списки скачиваются в `%APPDATA%\ExitBoost\lists` и обновляются не чаще раза
в неделю; без сети используется последняя копия. Полный реестр даёт максимальный
охват, но конфиг VPN вырастает до ~50 МБ, а ядро стартует на несколько секунд
дольше — поэтому по умолчанию выключен.

## Безопасность сети

- Маршрут по умолчанию системы **не изменяется**: VPN работает через TUN-адаптер
  и правила маршрутизации, которые удаляются при отключении.
- При падении VPN интернет продолжает работать, а не пропадает.
- При выходе приложение отключает VPN, останавливает обход DPI и принудительно
  снимает драйвер — «осиротевших» процессов не остаётся.

## Требования

- Windows 10/11 x64
- Права администратора (TUN-адаптер, маршруты, драйвер WinDivert)
- Для сборки — .NET SDK 8

Готовая сборка в `publish\ExitBoost` **не требует установленного .NET**:
рантайм лежит рядом с программой.

## Сборка

```powershell
dotnet build
dotnet test

# публикация: publish\ExitBoost, publish\ExitBoost.Cli,
# архивы, установщик, update.json и release.json в publish\release
powershell -ExecutionPolicy Bypass -File scripts\publish.ps1
```

Приложение собирается как self-contained (`win-x64`), поэтому работает и на
машинах без .NET.

## VPN по ключу

1. Вкладка «Подключение» → в левой панели «Добавить ключ…».
2. Вставьте ключ (`vless://…`, `vmess://…`, `trojan://…`, `ss://…`,
   `hysteria2://…`) или ссылку на подписку — ключи распакуются автоматически.
3. Выберите точку в таблице (там же пинг, потери и качество) и нажмите
   «Подключить VPN». Двойной клик по строке локации делает то же самое и
   заодно включает обход DPI (если в каталоге выбрана стратегия).

Подписки часто требуют заголовок с HWID — приложение отправляет свой
стабильный идентификатор из `%APPDATA%\ExitBoost\vpn\hwid.txt`.

Транспорты `xhttp`/`splithttp` ядро sing-box не поддерживает: такие ключи
пропускаются с пояснением в журнале.

## Обход DPI

Вкладка «Обход DPI»: обновление движка zapret, проверка стратегий на выбранных
доменах, автоподбор лучшей и запуск. Каталог стратегий — Flowseal.
Кнопка «Снять принудительно» убивает все процессы zapret и выгружает драйвер.

## Обновления с GitLab

Обновления всегда скачиваются только с официального репозитория
`karpachv99/ExitBoost` на GitLab — источник в приложении не выбирается.

Как это работает:

1. Приложение запрашивает последний релиз GitLab и читает манифест
   `update.json`: версию, размер архива и SHA-256.
2. Архив скачивается по HTTPS с докачкой по `Range`; после загрузки размер и
   SHA-256 проверяются ещё раз.
3. Запускается отдельный `ExitBoost.Updater.exe` (копия в
   `%LOCALAPPDATA%\ExitBoost\updates`). Он ждёт выхода приложения, распаковывает
   архив в staging, переименовывает текущую папку установки в `*.old`,
   ставит новую, запускает её и проверяет, что процесс жив.
4. Если что-то пошло не так — папка установки возвращается из `*.old`,
   а результат и журнал пишутся в `%LOCALAPPDATA%\ExitBoost\logs`.

Установщик `unins*.exe`/`unins*.dat` сохраняется при обновлении, поэтому
удаление программы продолжает работать.

> Версии 1.0.16 и старше содержали ошибку параллельной загрузки: они скачивали
> только часть архива. Для перехода на 1.0.17 их нужно один раз обновить
> вручную через `setup.exe`; начиная с 1.0.17 обновления идут автоматически.

Выпуск новой версии:

```powershell
# 1. поднять <Version> в src\ExitBoost.App\ExitBoost.App.csproj
# 2. собрать всё и получить update.json + команды загрузки
powershell -ExecutionPolicy Bypass -File scripts\publish.ps1
# 3. загрузить ZIP, setup, CLI ZIP и update.json в Package Registry,
#    затем создать релиз из publish\release\release.json (команды печатает скрипт)
git tag v1.0.17
git push gitlab v1.0.17
```

Манифест и архивы публикуются в GitLab Package Registry; GitHub остаётся
зеркалом для старых версий.

## Консольный клиент

```
ExitBoost vpn install                 скачать ядро sing-box
ExitBoost vpn keys add <ключ|URL>     добавить ключ или подписку
ExitBoost vpn keys list               список ключей
ExitBoost vpn keys remove <id>        удалить ключ
ExitBoost vpn connect <id|--best>     подключить VPN
ExitBoost vpn disconnect              отключить VPN
ExitBoost vpn status                  состояние VPN
ExitBoost dpi install|list|apply|stop обход DPI (zapret)
ExitBoost force-stop                  снять zapret и драйвер WinDivert принудительно
ExitBoost dpi check                   проверить домены на обход
```

## Ограничения

- Windows-only: TUN-адаптер, маршруты и WinDivert.
- Для одновременной работы VPN и обхода DPI используются разные драйверы
  (TUN и WinDivert); при проблемах с сетью сначала снимайте обход DPI.
- Скорость зависит от выбранного сервера: приложение показывает пинг и потери,
  но не гарантирует качество чужого сервера.

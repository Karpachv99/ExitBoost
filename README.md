# ExitBoost — VPN по ключу и обход DPI для Windows

Приложение для Windows: подключается к VPN по обычному ключу (VLESS, VMess,
Trojan, Shadowsocks, Hysteria2 — как в Happ), пускает через него только нужные
сайты и программы (или весь трафик — с подтверждением) и умеет обходить
блокировки DPI через движок zapret.

Есть графическое приложение (WPF) и консольный клиент.

---

## Возможности

| Возможность | Как работает |
|---|---|
| VPN по ключу | Ядро sing-box, ключи вставляются строкой или загружаются подпиской по ссылке |
| Выбор точек доступа | Список ключей с узлом, страной, пингом, потерями, джиттером и оценкой качества |
| Раздельное подключение | По умолчанию — только выбранные сайты и программы; весь трафик — с явным подтверждением |
| Обход DPI | zapret + каталог стратегий Flowseal (14 пресетов), автоподбор и проверка |
| Полная очистка | При выходе гасятся VPN, все процессы zapret и драйвер WinDivert |
| Обновления | Проверка релизов на GitHub, скачивание архива и перезапуск на новой версии |
| Консольный клиент | Те же действия из командной строки |

## Безопасность сети

- Маршрут по умолчанию системы **не изменяется**: VPN работает через TUN-адаптер
  и правила маршрутизации, которые удаляются при отключении.
- Нет kill-switch: при падении VPN интернет продолжает работать, а не пропадает.
- При выходе приложение отключает VPN, останавливает обход DPI и принудительно
  снимает драйвер — «осиротевших» процессов не остаётся.

## Требования

- Windows 10/11 x64
- Права администратора (TUN-адаптер, маршруты, драйвер WinDivert)
- Для сборки — .NET SDK 8

Готовая сборка в `publish\ExitBoost` **не требует установленного .NET**:
рантайм лежит рядом с программой.

## Сборка

```powershell
dotnet build
dotnet test

# публикация: папки publish\ExitBoost, publish\ExitBoost.Cli
# и архивы для GitHub Releases в publish\release
powershell -ExecutionPolicy Bypass -File scripts\publish.ps1
```

Приложение собирается как self-contained (`win-x64`), поэтому работает и на
машинах без .NET.

## VPN по ключу

1. Вкладка «Подключение» → в левой панели «Добавить ключ…».
2. Вставьте ключ (`vless://…`, `vmess://…`, `trojan://…`, `ss://…`,
   `hysteria2://…`) или ссылку на подписку — ключи распакуются автоматически.
3. Выберите точку в таблице (там же пинг, потери и качество) и нажмите
   «Подключить».

Подписки часто требуют заголовок с HWID — приложение отправляет свой
стабильный идентификатор из `%APPDATA%\ExitBoost\vpn\hwid.txt`.

Транспорты `xhttp`/`splithttp` ядро sing-box не поддерживает: такие ключи
пропускаются с пояснением в журнале.

## Обход DPI

Вкладка «Обход DPI»: обновление движка zapret, проверка стратегий на выбранных
доменах, автоподбор лучшей и запуск. Каталог стратегий — Flowseal.
Кнопка «Снять принудительно» убивает все процессы zapret и выгружает драйвер.

## Обновления с GitHub

1. Создайте релиз (тег `v1.0.1`) — workflow `.github/workflows/release.yml`
   соберёт приложение и приложит архивы к релизу.
2. В приложении: «Подключение» → «Обновления» → укажите репозиторий
   `владелец/имя`. При запуске программа проверит свежий релиз, предложит
   установку, скачает архив, перезапустится и распакует его поверх себя.

Выпуск новой версии:

```powershell
dotnet build -p:Version=1.0.1
git tag v1.0.1
git push --tags
```

## Консольный клиент

```
ExitBoost vpn install                 скачать ядро sing-box
ExitBoost vpn keys add <ключ|URL>     добавить ключ или подписку
ExitBoost vpn keys list               список ключей
ExitBoost vpn keys remove <id>        удалить ключ
ExitBoost vpn connect <id|--best>     подключить VPN
ExitBoost vpn disconnect              отключить VPN
ExitBoost vpn status                  состояние VPN
ExitBoost dpi install|list|apply|stop обход DPI (zapret)
ExitBoost force-stop                  снять zapret и драйвер WinDivert принудительно
ExitBoost dpi check                   проверить домены на обход
```

## Ограничения

- Windows-only: TUN-адаптер, маршруты и WinDivert.
- Для одновременной работы VPN и обхода DPI используются разные драйверы
  (TUN и WinDivert); при проблемах с сетью сначала снимайте обход DPI.
- Скорость зависит от выбранного сервера: приложение показывает пинг и потери,
  но не гарантирует качество чужого сервера.
